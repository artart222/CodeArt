# CodeArt documentation

Guides for **CodeArt 2.1** (Neovim 0.12+). This `docs/` folder is the source of truth.

The [GitHub wiki](https://github.com/artart222/CodeArt/wiki) is updated from here via `scripts/sync-wiki.sh` (and CI on pushes to `main` that touch `docs/`). Edit these files — do not hand-edit the wiki long-term.
